# Domain Ontology

Layer A/B/C 각각의 노드·관계 스키마.

## 작성 예정

- `doc-ontology.md`: Document/Section/Chunk/Table 스키마 (W2)
- `entity-ontology.md`: Company/Metric/Risk/Outlook (W2)
- `community-ontology.md`: Community/Topic + 군집 알고리즘 선택 (W3 후반)

## 참고

- FIBO (Financial Industry Business Ontology): https://spec.edmcouncil.org/fibo
- 기존 레포 `chunker/chunker.py`의 `_SECTION_TYPE_MAP`, `_METRIC_KEYWORDS` — 정규식 기반 추출의 한계를 그대로 도메인 스키마 설계의 출발점으로 활용
