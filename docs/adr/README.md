# Architecture Decision Records (ADR)

주요 설계 결정의 기록. 각 ADR은 다음 형식을 따른다:

```
# ADR NNNN: 결정 제목

## Status
Proposed | Accepted | Deprecated | Superseded by ADR-XXXX

## Context
어떤 상황에서 결정이 필요했는가

## Decision
무엇을 결정했는가

## Consequences
좋은 점, 나쁜 점, 트레이드오프
```
